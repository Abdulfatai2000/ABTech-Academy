# Design system

Blue actions, white surfaces, deep navy text and restrained teal accents support a calm learning experience. Semantic CSS variables provide light and dark palettes. System sans-serif and monospace stacks avoid network-dependent font builds.

The content container is 1160px; spacing follows an approximately 8px rhythm. Cards use subtle borders, not heavy shadows. One main activity occupies each lesson step. Mobile layouts collapse to one column at 760px. Controls have visible focus, meaningful labels and at least 40px height. Motion respects reduced-motion preferences. Roadmap states include text, not color alone.

Shared primitives: button links, badges, cards, breadcrumbs, callouts, empty and loading states. Native details/summary controls provide keyboard-accessible progressive disclosure.
