# Four-week beginner study path

This is a suggested plan, not an automatic schedule or completion guarantee. Start with JavaScript before React Native if you have never used React.

## Week 1 — JavaScript foundations
- Read **Values and variables** and **Decisions with conditionals**.
- Predict each example's output before checking it.
- Write a small age eligibility checker using `if/else`.
- Self-check: Can you explain `const`, `let`, strict equality, and branching?

## Week 2 — Functions and arrays
- Read **Functions and arrays**.
- Write a function that receives an array of scores and returns the average.
- Test empty arrays and invalid inputs deliberately.
- Self-check: Can you distinguish a function parameter from an argument?

## Week 3 — React Native fundamentals
- Read **Components and props**.
- Build a static profile card with `View`, `Text`, and reusable props.
- Self-check: Can you explain how a parent passes data to a child?

## Week 4 — State and interaction
- Read **Making your app interactive with useState**.
- Build a counter and a controlled text input in an external Expo project.
- Self-check: Why must state updates use setters instead of direct assignment?

## How to practice
Spend 20 minutes reading, 30 minutes coding, and 10 minutes reflecting per session. Use the platform's bookmark and reading progress features to resume. The on-page practice editor is not a code runner: test runnable examples in Expo or another suitable environment. Later roadmap modules are planned and may not yet have lessons.
